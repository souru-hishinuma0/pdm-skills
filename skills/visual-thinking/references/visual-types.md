# 表現の型カタログ

素材の種類と問いから引く。各型の項目：向いている問い / 描き方のコツ / 落とし穴

## 量（定量）

### 散布図（2軸）
- 向いている問い：二つの指標に関係があるか。どこに偏りや外れ値があるか
- コツ：点を顧客や製品などの単位にする。自社や注目対象を強調する
- 落とし穴：相関を因果と読む

### 両対数グラフ
- 向いている問い：規模や経験が増えるとコストや効率がどう変わるか（エクスペリエンスカーブ、スケールカーブ）
- コツ：直線になれば一定の比率で改善している。傾きが改善率
- 落とし穴：データ点が少ないと、直線に見えるだけのことがある

### 棒・積み上げ棒
- 向いている問い：構成要素の内訳と大小（コスト構造、売上の構成）
- コツ：比較したい項目を隣に並べる。積み上げは要素の数を絞る
- 落とし穴：積み上げの中段の要素は比較しにくい

### コホート曲線
- 向いている問い：獲得時期ごとに、継続率や顧客あたり売上がどう推移するか
- コツ：横軸を「獲得からの経過期間」にそろえる
- 落とし穴：最近のコホートほどデータが短く、判断が早すぎる

### パレート図・分布
- 向いている問い：少数が全体の大部分を占めていないか（売上、利用量、コスト）
- コツ：降順に並べ、累積比率の線を重ねる
- 落とし穴：平均値だけを見て分布の偏りを見逃す

### マリメコ図
- 向いている問い：市場をセグメント別の大きさと各社のシェアで同時に見る
- コツ：横幅をセグメントの大きさ、縦をシェアにする
- 落とし穴：数字の精度が低いと、見た目の印象だけが一人歩きする

## 位置（定性・定量の両方）

### 2×2マトリクス
- 向いている問い：対象を二つの観点で分類し、どこに何があるか（優先度、顧客の類型、施策の選別）
- コツ：二つの軸を互いに独立させる。各象限に名前を付け、取るべき行動を書く
- 落とし穴：軸が似ていると、対象が対角線上に並ぶだけになる

### ポジショニングマップ
- 向いている問い：競合の中で自社がどこにいるか。空いている場所はどこか
- コツ：顧客が実際に選ぶときに重視する軸を使う
- 落とし穴：空白地帯に需要があるとは限らない

## 構造（定性中心）

### レイヤー図（スタック）
- 向いている問い：どの層で価値が生まれ、誰がどの層を握っているか（例：モデル／アプリ／業務）
- コツ：層ごとに主なプレイヤーと、価値や利益の厚さを示す
- 落とし穴：層の境界が実際には曖昧なことを無視する

### バリューチェーン分解図
- 向いている問い：機能や工程ごとに、誰が強いか。どこが切り出されているか（デコンストラクション）
- コツ：工程を横に並べ、各工程に強いプレイヤーを置く
- 落とし穴：工程を細かくしすぎて、全体の流れが見えなくなる

### ツリー（イシューツリー、KPIツリー）
- 向いている問い：大きな問いや指標を分解し、どこが効いているか
- コツ：同じ階層の要素を漏れなく重複なく分ける。仮説の枝を太くする
- 落とし穴：分解が目的化して、どこを掘るかの判断がない

## 関係・流れ（定性中心）

### エコシステム図（プレイヤー関係図）
- 向いている問い：誰が誰にお金・データ・価値を渡しているか。力関係はどうなっているか
- コツ：矢印の種類（お金、データ、製品）を色や線種で分ける
- 落とし穴：プレイヤーを並べるだけで、流れの向きと量が描かれていない

### 因果ループ図
- 向いている問い：何が何を強めたり弱めたりしているか。好循環と悪循環はどこにあるか（フライホイール、ネットワーク効果）
- コツ：矢印に＋（同じ向きに動く）か−（逆向きに動く）を付け、ループが強化型か抑制型かを示す
- 落とし穴：要素を増やしすぎてループが読めなくなる

### 業務フロー図・データフロー図
- 向いている問い：顧客の業務のどこに自社が入り込んでいるか。データの正本はどこか
- コツ：顧客側の業務を主役にし、自社の介入点を重ねる
- 落とし穴：自社製品の画面遷移を描いてしまい、顧客業務が見えなくなる

## 時間

### タイムライン
- 向いている問い：出来事の順序と、競争環境の変化点
- コツ：自社、競合、市場の出来事を別の行に分ける
- 落とし穴：出来事を並べるだけで、変化点の意味を書かない

### ビフォー・アフター
- 向いている問い：戦略や施策で何がどう変わるか
- コツ：同じ型の図を左右に並べ、変わる部分だけを強調する
- 落とし穴：変わらない前提を書き忘れる

### Now / Next / Later
- 向いている問い：段階的な移行や投資の順序
- コツ：各段階に「次へ進む条件」を書く
- 落とし穴：時期だけを書いて、進む条件が書かれていない

## 比較

### 並列比較表・評価表
- 向いている問い：複数の選択肢を同じ観点で比べる（戦略オプション、競合比較）
- コツ：観点は判断に効くものに絞る。評価は記号（◎○△×、ハーベイボール）で一目で分かるようにする
- 落とし穴：観点が多すぎて、どれが決め手か分からなくなる
