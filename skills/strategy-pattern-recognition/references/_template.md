# パターン追加テンプレート

戦略業務で新しい型に気づいたとき、または「該当なし」だった事例があったとき、以下の形式で追加する。
領域に合うファイル（common / b2b-saas / ai-product）に追記する。新しい領域なら新しいファイルを作り、SKILL.md の表に追加する。

```
### [ID]. [パターン名]
- 出典：定石 / 自社経験（いつ、どの案件。公開リポジトリでは固有名詞を伏せる）
- 状態：候補 / 正式
- 症状：
- 構造：
- 確認：
- 反証：
- 定石：
- 落とし穴：
- 元概念：
```

## 追加のルール
- 「症状」は観測できる事実で書く（解釈を混ぜない）
- 「反証」が書けないものはパターンではなく思い込みとして保留する
- 自社経験のパターンは、1件だけなら「候補」、2件以上の事例で確認できたら「正式」にする
- 既存パターンと重なる場合は、新規追加ではなく既存カードの症状や反証を更新する
- 公開リポジトリに置くため、顧客名・社名・未公開の数値は書かない
