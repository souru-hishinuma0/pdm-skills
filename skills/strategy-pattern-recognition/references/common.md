# A. 領域横断パターン

カードの項目：症状 / 構造（なぜ起きるか）/ 確認 / 反証 / 定石 / 落とし穴 / 元概念 / シグネチャー図（仮説どおりなら見える形）

### A1. 平均値の罠
- 症状：全体KPIは横ばい、または緩やかに変化しているが、施策を打っても効果が読めない
- 構造：性質の違うセグメントが混在していて、真逆の動きが平均で打ち消し合っている
- 確認：顧客規模・業種・獲得チャネル・利用目的別にKPIを分解する
- 反証：どの切り方でもセグメント間の差が小さい
- 定石：勝っているセグメントを特定して資源を寄せる。負けているセグメントは撤退か作り直しかを決める
- 落とし穴：切り口を増やしすぎて、偶然の差をセグメントの違いと誤認する
- 元概念：セグメンテーション
- シグネチャー図：セグメント別KPI推移の重ね線グラフ → 全体は横ばいで、セグメントは逆向きに動いている

### A2. 中途半端なポジション
- 症状：大手には機能・ブランドで負け、専業には特定用途の深さで負ける。勝ち負けの理由が「どっちつかず」
- 構造：シェア中位の会社は規模の経済も専門性も持てず、収益性が最も低くなりやすい
- 確認：失注理由を相手別（大手／専業）に分類する。セグメント別の勝率と粗利
- 反証：特定セグメントでは明確に勝っていて、問題は営業の当て先だけ
- 定石：規模で勝ちに行くか、ニッチで深さを取るかを決めて振り切る
- 落とし穴：「両方やる」を選び続けてロードマップが分散する
- 元概念：V字カーブ、アドバンテージ・マトリクス
- シグネチャー図：シェア × 粗利率の散布図 → V字の谷に自社がいる

### A3. ローエンドからの侵食
- 症状：機能が足りないと見下していた安価な製品に、下位セグメントから顧客を奪われ始める
- 構造：既存顧客の要求に応えて高機能化するうちに、多くの顧客にとって性能が過剰になる。そこに安くて十分な製品が入り込み、徐々に上位へ上がってくる
- 確認：失注先の顧客規模の推移。自社の主要機能を実際に使っている顧客の割合
- 反証：侵食者が上位セグメントの要件（セキュリティ、統制、連携）を長く満たせていない
- 定石：別ブランドや別組織で低価格帯を自ら取りに行く。上位セグメントでしか成り立たない価値に集中する
- 落とし穴：既存の粗利を守るため、対応が手遅れになる
- 元概念：破壊的イノベーション
- シグネチャー図：時間 × 性能のチャートに顧客の要求水準の線を引く → 自社は要求を大きく超え、侵食者がその線に近づいている

### A4. アンバンドリング
- 症状：自社製品の一機能だけを切り出した専業プレイヤーが増え、その機能領域で負け始める
- 構造：バリューチェーンや製品の一部だけで勝負できるようになり、統合型の優位が崩れる
- 確認：専業に流れた顧客が、自社の他機能を使い続けているか
- 反証：統合による価値（データの一貫性、運用負荷の低さ）を顧客が重視している
- 定石：統合の価値を前面に出すか、その機能はパートナー連携に切り替えてコアに集中する
- 落とし穴：全機能で専業に対抗しようとして全部が中途半端になる
- 元概念：デコンストラクション
- シグネチャー図：バリューチェーン分解図に、機能ごとに強いプレイヤーを置く → 自社の領域が機能単位で専業に塗り替わっている

### A5. 先行者の幻想
- 症状：「先に出せば勝てる」という前提で、検証が不十分なまま市場投入を急いでいる
- 構造：先行者が勝つのは、ネットワーク効果・スイッチングコスト・希少資源の確保など、先行した優位が固定される仕組みがあるときだけ。それ以外では後発のほうが学習コストを払わずに済む
- 確認：先行で得られる優位が固定される仕組みが具体的に存在するか
- 反証：ネットワーク効果や乗り換えの手間が明確にあり、時間とともに強くなる
- 定石：固定の仕組みがなければ、速さより学習の質を優先する。または先行者の失敗を観察してから入るファスト・フォロワーを選ぶ
- 落とし穴：「スピードが大事」という一般論で判断を省略する
- 元概念：ファースト・ムーバー・アドバンテージ、プリエンプティブ・アタック
- シグネチャー図：自社・競合・市場のタイムラインに、先行優位を固定する仕組みを注記する → 固定の仕組みの欄が空白

### A6. 新規事業の窒息
- 症状：新プロダクトが2〜3年経っても立ち上がらない。毎回の計画で売上目標未達を問われる
- 構造：既存事業のKPI、予算プロセス、営業体制で新規事業を評価・運営している
- 確認：新規事業のKPIと評価会議の形式。既存営業の報酬が新規製品の販売に連動しているか
- 反証：独立した評価軸と体制があるのに伸びていない（それなら別の問題）
- 定石：フェーズに合ったKPI（学習指標、先行指標）で評価する。組織や販売チャネルを分ける
- 落とし穴：分離しすぎて、既存事業の資産（顧客基盤、データ）を使えなくなる
- 元概念：組織能力、イノベーションのジレンマ
- シグネチャー図：既存事業と新規事業のKPI・評価プロセスの並列比較表 → 新規事業の欄が既存事業の指標で埋まっている
